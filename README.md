## 🚀 Quick Start

### 📋 Prerequisites

- **Node.js** `>= 18.0.0`
- **npm** / **pnpm** / **bun**

### 💻 Installation & Execution

```bash
# Clone the repository
git clone [https://github.com/ziyadparkar01/Paper-Trail.git](https://github.com/ziyadparkar01/Paper-Trail.git)

# Navigate to project root
cd Paper-Trail

# Install dependencies
npm install

# Launch the local development server
npm run dev
